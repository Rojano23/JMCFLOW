# RELEASE-CHECKLIST

Checklist final antes de publicar una version de RX23 o un sitio derivado.

## Calidad tecnica
- [ ] npm run lint exitoso
- [ ] npm run build exitoso
- [ ] dist generado sin errores

## QA visual y responsive
- [ ] Mobile validado
- [ ] Tablet validado
- [ ] Desktop validado
- [ ] Navegacion por anclas validada

## Configuracion funcional
- [ ] Feature flags revisados
- [ ] Secciones activas tienen contenido real
- [ ] Contacto validado (email, telefono, direccion)
- [ ] WhatsApp validado

## SEO basico
- [ ] title y description configurados
- [ ] keywords configuradas
- [ ] canonical configurada para dominio real
- [ ] Open Graph validado (title, description, image, type)
- [ ] favicon configurado

## Enlaces
- [ ] Enlaces internos funcionando
- [ ] Enlaces externos funcionando
- [ ] Redes sociales con URLs validas o flag desactivado

## Documentacion
- [ ] README actualizado
- [ ] Documentacion de cliente actualizada si hubo cambios
- [ ] Reporte de sprint actualizado

## Cierre
- [ ] Version/tag definida
- [ ] Commit final limpio
- [ ] Entorno de deploy seleccionado
