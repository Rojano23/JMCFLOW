# RX23 v1.1 BrandsGallery

## Objetivo
Incorporar una seccion opcional reusable llamada BrandsGallery a la plantilla RX23 sin acoplarla al cliente actual y manteniendo la arquitectura basada en datos, tipos, secciones y feature flags.

## Arquitectura
- Los contratos viven en `src/types/index.ts`.
- El contenido editable vive en `src/data/gallery.ts`.
- La visibilidad se controla desde `src/data/features.ts` mediante `gallery`.
- La composicion visual vive en `src/sections/BrandsGallery/`.
- La pagina integra la seccion desde `src/pages/HomePage.tsx` respetando el orden general de la plantilla.

## Feature Flag
Agregar o ajustar el flag en `src/data/features.ts`:

```ts
export const features: FeatureFlags = {
  about: true,
  services: true,
  industries: true,
  projects: true,
  differentiators: true,
  gallery: false,
  whatsapp: true,
  socialLinks: true,
  contactForm: false,
  maps: false,
};
```

Comportamiento:
- `gallery: false` oculta por completo la seccion y su enlace de navegacion.
- `gallery: true` habilita la seccion, siempre que exista contenido en `brands` o `products`.

## Estructura de datos
Archivo: `src/data/gallery.ts`

```ts
export const gallery: GalleryContent = {
  sectionEyebrow: 'Galeria de marca',
  sectionTitle: 'Brands Gallery',
  sectionSubtitle: 'Descripcion opcional de la seccion',
  brandsTitle: 'Marcas representadas',
  productsTitle: 'Equipos e instrumentacion',
  brands: [],
  products: [],
};
```

Tipos relacionados:
- `BrandItem`: `{ name: string; logo: string }`
- `ProductItem`: `{ title: string; image: string }`
- `GalleryContent`: objeto contenedor de titulos y colecciones.

## Como agregar logos
1. Colocar los archivos de logo en `public/` o `src/assets/` segun la estrategia del proyecto.
2. Referenciar cada logo en `src/data/gallery.ts`.

Ejemplo:

```ts
brands: [
  {
    name: 'Marca Ejemplo',
    logo: '/brands/marca-ejemplo.svg',
  },
],
```

## Como agregar imagenes de equipos
1. Colocar las imagenes en `public/` o `src/assets/`.
2. Registrar cada elemento en `src/data/gallery.ts`.

Ejemplo:

```ts
products: [
  {
    title: 'Analizador Portatil',
    image: '/products/analizador-portatil.jpg',
  },
],
```

## Como habilitar o deshabilitar la seccion
1. Abrir `src/data/features.ts`.
2. Cambiar el valor del flag `gallery`.
3. Verificar que `src/data/gallery.ts` contenga datos si la seccion se habilita.

## Comportamiento UX
- Se muestran dos carruseles independientes: marcas y productos.
- El desplazamiento es continuo, suave y sin controles.
- Los items se duplican internamente para evitar saltos visibles en el loop.
- La animacion se pausa al pasar el cursor o al enfocar contenido dentro del carrusel.
- Todas las imagenes se renderizan con `alt` derivado del contenido configurado.

## Validacion recomendada
1. `npm run lint`
2. `npm run build`
3. Revisar responsive en movil, tablet y desktop.
4. Confirmar que la seccion no renderiza si el flag esta apagado o si no existen items.
